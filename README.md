# URL Checker

Консольная программа на Go для проверки HTTP-адресов. Для каждого адреса показывает HTTP-статус, время запроса или ошибку.

Учебный проект, на котором я разбираюсь с HTTP, горутинами, каналами и тестированием в Go.

## Как работает

- Каждый адрес проверяется в отдельной горутине. Канал `slots` ограничивает число одновременных проверок: перед запуском занимаем место, после завершения освобождаем его.
- Функция `checkURL` возвращает структуру с результатом. Горутина отправляет её в канал `results`, из которого затем читает `main`.
- `sync.WaitGroup` позволяет дождаться всех проверок. После этого `main` закрывает канал результатов и выводит их в консоль.

## Запуск

Нужен установленный Go. Версия проекта указана в `go.mod`. Команды выполняются из папки проекта.

```shell
go run . https://go.dev https://example.com
```

По умолчанию выполняется до трёх проверок одновременно, таймаут каждого запроса — 5 секунд. Эти настройки можно изменить:

```shell
go run . -concurrency 2 -timeout 3s https://go.dev https://example.com
```

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| `-concurrency` | Максимальное число одновременных проверок | `3` |
| `-timeout` | Таймаут одного запроса | `5s` |

Оба значения должны быть больше нуля. Параметры нужно указывать перед адресами. У адресов должна быть схема `http://` или `https://`.

Справка:

```shell
go run . -h
```

## Тесты

```shell
go test -v ./...
```

Проверяются четыре сценария: ответ `200`, ответ `500`, некорректный URL и таймаут. Для HTTP-запросов используется локальный тестовый сервер, поэтому внешний интернет не нужен.

## Особенности

- Результаты выводятся после завершения всех проверок. Их порядок может отличаться от порядка переданных адресов.
- Время измеряется до получения заголовков ответа или ошибки. Скачивание всей страницы не измеряется.
- HTTP-статусы `4xx` и `5xx` выводятся как ответы сервера. Ошибки выполнения запроса, например таймаут, выводятся отдельно.
